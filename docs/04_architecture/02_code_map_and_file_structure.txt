2. SYMMETRIC MIRROR-PAIR DEDUPLICATION MECHANICS
-------------------------------------------------------------------------------
To prevent duplicate row entries when Record A (Bank) matches Record B (Gateway), 
`frontend/api/routes.py` applies symmetric pair deduplication in `_build_dashboard_run()`:

  seen_matched_ids = set()
  for tx in all_reconciled_transactions:
      p_id = str(tx.get("primary_id"))
      c_id = str(tx.get("counterpart_id"))
      
      pair_key = (p_id, c_id)
      reverse_key = (c_id, p_id)
      
      if pair_key in seen_matched_ids or reverse_key in seen_matched_ids:
          continue
